Pastor mode — UI hi-fi with anti-surveillance constraints

Pastor mode is shepherding, not surveillance. Every pixel must refuse the dossier shape. Doctrine: Yakobus 5:16 (mutual confession requires mutual visibility) + Wahyu 3:20 (door-knocking, never door-breaking). All copy in Indonesian (TB2).

Why this exists

Asymmetric information is a dossier, not discipleship. The visual frame must refuse the dossier shape — Maya sees what Pastor sees, when he saw it.

  • Real-time mirror. Every read by Pastor surfaces here within seconds.
  • No "delete from history". Mirror is append-only while mode is active.
  • Includes pastor's notes. Anything pastor wrote to user is mirrored back so user can re-read.
  • Does NOT show pastor's other audited users. Maya only sees activity that touches her own threads.
“Hendaklah kamu saling mengaku dosamu seorang kepada yang lain.” Yakobus 5:16 · TB2 — symmetry is mutual, not one-way.

Negative-case documentation · do not reintroduce

Rejected iconography — and why

Reviewed and rejected for pastor-mode contexts. Each rejection has a doctrinal reason; future Designer work cannot reintroduce these without re-litigating the Holy Code of Conduct.

Ditolak · panopticon

Mata (eye)

The eye in a mentor-audit context reads as panopticon — the watcher whose presence shapes the behavior of the watched. That is the opposite of shepherding: a shepherd walks alongside, not above.

“Lihatlah, Aku berdiri di muka pintu dan mengetuk.” — Wahyu 3:20. Christ knocks; He does not stare in.

Ditolak · investigation

Kaca pembesar (magnifying glass)

Investigation glyph. Implies the audited user is a case to be solved or evidence to be examined. Pastoral relationships are not investigations and the mentee is not a suspect.

Yakobus 5:16 frames mutual confession as healing, not forensics.

Ditolak · carceral

Gembok (lock / security)

Lock and security glyphs frame the relationship as containment — keeping the user "safe" from themselves. Pastor mode is a covenant of trust, not a containment system. Lock semantics also blur with auth/account-security UI elsewhere in the app.

Containment is a prison metaphor. Discipleship is a road metaphor (Lukas 24).

Ditolak · authority armor

Perisai (shield)

Shield reads as authority defending downward. It positions Pastor over the user instead of beside. It is also visually adjacent to security/admin-panel chrome — wrong frame for a covenant.

Authority that protects from above is not the shepherd model of Mazmur 23.

Ditolak · scoring

Bintang / nilai

Star, badge, and score iconography (gamification rewards) collapse a covenant relationship into a metric. Avoiding "engagement scores" means avoiding the visual language of scoring entirely.

Spiritual maturity is not a leaderboard. Refuse the ranking shape.

Ditolak · approval gating

Tanda centang “disetujui pendeta”

"Pastor-approved" verification badges frame the user as something to be certified. Two-party consent is not approval-of-person; it is approval-of-relationship. Removing the certification glyph removes the certification framing.

Approval-of-person creates spiritual-class hierarchy — Galatia 3:28 forbids it.

Approved iconography

Used throughout the surfaces above. Three glyphs cover the vocabulary; we extend within them, never outside.

Diterima

Tongkat gembala

Pastoral metaphor by direct etymology. Mazmur 23: "tongkat-Mu menghibur aku."

Diterima

Dua sosok bersisian

Two figures side by side. Walking-companion frame, not authority-over.

Diterima

Pejalan beriring

Walking same direction; one slightly behind, never above. Used on the benediction screen.
