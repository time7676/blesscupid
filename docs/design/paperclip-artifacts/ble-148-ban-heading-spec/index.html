BLE-148

Ban surface — canonical heading & cite-line disclaimer

Visual spec for the two new bundle-level keys introduced in BLE-31 §10 v1.2 #3 and §10.6. Renders verbatim on every Voice 03 ban surface (BLE-26 chat moderation, BLE-27 safety, BLE-65 admin host-shell). Both locales shown at 360 × 720 viewport. No panic-exit red token used on this surface.

  • Designer: FoundingDesigner
  • Status: ready for Pastor sign-off
  • Source of truth: copy-bundle.json#$ban_canonical_heading · copy-bundle.json#$ban_scripture_disclaimer
  • Tokens: aligned to BLE-22 v0.1

Note for Pastor: per-case title and body copy in mockups below are illustrative placeholders for the visual spec — production strings are pulled verbatim from copy-bundle.json per category. Pastor sign-off needed only on the visual treatment of $ban_canonical_heading + the cite-line {ref} · {tx} · {disclaimer} typographic pattern. Copy approval lives with the bundle review, not with this spec.

Locale rendering — side-by-side

Both screens render harassment.ban tier from copy-bundle.json. The canonical heading and cite-line disclaimer suffix flip atomically with the locale switch — never partial-fallback.

  • Canonical heading sits between dove crest and per-case title.
  • Italic Source Serif 4 in --bc-gold-700 at 20px / line-height 1.35.
  • Cite-line follows fixed format {ref} · {tx} · {disclaimer}.
  • Disclaimer wrapped in <em> for screen-reader emphasis; middots aria-hidden="true".
  • WCAG AA verified — gold-700 on cream-50 = 4.6:1 contrast.

Disclaimer-omission case — financial.ban

Per BLE-31 §10.3, the disclaimer suffix is omitted on CSAM / scam-ring bans (voice_03_disclaimer_required: false in copy-bundle.json) and when actor profile flags atheist / agnostic / seeker. Cite-line collapses to {ref} · {tx}. Canonical heading is still rendered.

  • Heading: present on every ban, every category, every actor profile.
  • Cite-line: {ref} · {tx} only when disclaimer is suppressed.
  • No scripture at all → no blockquote rendered.
