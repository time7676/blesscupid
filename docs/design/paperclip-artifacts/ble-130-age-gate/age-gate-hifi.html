18+ age gate — pastor-mode prerequisite

Above 18 is the threshold of competent consent. The age gate is the doormat: nothing pastor-mode-shaped can be invited or accepted without it. Surveillance-adjacent surfaces on a minor are mandatory-reporting risk under UU Perlindungan Anak; two-party consent does not absolve platform liability when one party is under 18. Default verification: Indonesian KTP/NIK DOB extraction; affidavit fallback only when KTP unavailable.

Constraint 1 · Doormat, not gatekeeper

1 · Doormat intro · 2 · KTP capture

Entry surface frames the gate as a threshold of consent, not a hostile checkpoint. Wahyu 3:20 doormat metaphor surfaces here exactly once — never reused as urgency or shame copy elsewhere. Constraint 2 · Minimum data, user confirms

3 · DOB review · 4 · Affidavit fallback

After OCR extracts DOB, user confirms or corrects before submission. This is the human-in-the-loop step. Affidavit is the no-KTP path: signed attestation under UU ITE Pasal 11 (electronic signature legality), bound to account by liveness selfie + IP timestamp. Affidavit failures still neutral — never reveals which check failed.

Constraint 3 · Neutral failure, no shame

5 · Processing · 6 · Pass · 7 · Neutral fail

Three terminal states. Processing has no progress bar (avoids "we're judging you" framing) — just steady spinner with reassuring copy. Pass surface is intentionally low-celebration; the gate is a doormat, not an achievement. Fail surface is the hardest piece: never says "you are too young", never reveals OCR vs document-quality vs DOB mismatch as the cause. Single neutral message, single redirect, no escalation path.

Surface 5 · Processing

Open questions for next heartbeat

  • OCR vendor. AWS Textract (managed, costs ~$1.50/1000 pages) vs Tesseract self-hosted (free, lower accuracy on KTP fonts) vs an Indonesian KTP-specialised vendor like Privy. Defer pick to BLE-69 counsel decision — affects PII processing-location rules.
  • Liveness on affidavit. Currently spec'd as required (Constraint 4). If counsel says affidavit alone is insufficient under UU Perlindungan Anak, the affidavit path is removed entirely — KTP becomes mandatory. Mark as launch-decision, not v1 scope.
  • Re-verification cadence. Once a user passes, do we re-verify on a schedule? Counsel input needed; default v1 is one-shot at first pastor-mode trigger, no re-verify.
  • Cross-region (non-ID). Out of scope v1; component should accept a locale prop now so region-specific adapters (PH, MY) plug in later without an API break.
