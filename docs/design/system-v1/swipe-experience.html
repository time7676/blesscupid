04 · Animation

Calm, never snappy

All swipe motion uses ease-emphatic. No spring overshoot. No bounce. Card exit is decisive but unhurried.

Banned

  • Spring overshoot on snap-back. Reads flirty.
  • Confetti, hearts-fly, scale-pop on Bless commit. Cathedral Light §HCoC.
  • Infinite restock. Empty deck shows "That's everyone for today" — never auto-fetch more.
  • Card flip for profile expand. Use bottom sheet (sheet variant=full).
  • Velocity-based rotation overshoot. Rotation caps at 18° regardless of flick speed.
05 · Button ↔ gesture parity

Tap fires same animation

Pass / Bless / Super-Bless buttons trigger the exact card-exit animation a gesture would. No second visual language. Single source of truth.

onPress flow
1. Haptic fires · 2. Button scales 0.94 (80ms) · 3. Card exits in direction (320ms emphatic) · 4. Next card rises (200ms, 80ms delay) · 5. Telemetry event committed.
Direction map
Pass → left exit. Bless → right exit. Super → up exit.
Disabled while animating
All three buttons + drag locked from press-down through next-card-rise complete (~600ms total). Prevents double-fire.
Tap target
Visual 64/72pt. hitSlop extends to 80pt for thumb-zone forgiveness.
Position
Anchored bottom · 64pt above safe-area inset · 24pt gutter · 24pt between.

07 · Accessibility / reduced motion

Every gesture has a button equivalent

  • Buttons are first-class. Whole swipe deck operable without gestures. VoiceOver / TalkBack reads card content + Pass / Bless / Super-Bless actions.
  • Reduced motion. System flag respected. Card exit becomes 200ms cross-fade — no rotate, no translate. Bless halo pulse disabled. Match ceremony skips 560ms reveal, fades in.
  • VoiceOver labels. Card = "{name}, {age}, {location}, {tradition}. Double-tap to view profile." Actions = "Pass on {name}", "Send Bless to {name}", "Super-Bless {name}".
  • Focus order. Card → Pass → Super → Bless. Bless last because it's primary (closest to dominant thumb).
  • Tap target floor. 48pt min on all controls (covered by 64/72pt visual). hitSlop on small icon affordances.
  • Color-blind safety. Action distinguished by shape + position + label, not color alone. Cobalt Bless vs gold Super-Bless reinforced by larger size + halo + position.
  • Undo. Last action reversible within 5s via Undo banner (sheet variant=top). Required — accidental Pass on right person is the worst-feeling bug.
08 · RN API (proposed)

Component contracts

<SwipeDeck
  cards={Card[]}            // {id, name, age, location, tradition, photoUri}
  onCommit={(id, action) => void}     // action: 'pass' | 'bless' | 'super'
  onEmpty={() => void}                 // last card committed
  onPeek={(id) => void}                // long-press → open profile sheet
  thresholds?={                        // override defaults
    horizontalDistance: 0.32,          // fraction of card width
    verticalDistance: 0.22,
    velocity: 800,
  }
  reducedMotion?={boolean}             // override system flag
/>

// internal:
<SwipeCard
  card
  isTop                                // top of stack receives gesture
  stackIndex                           // 0,1,2 → scale + translateY behind
  onCommit                             // animates exit
/>

<ActionDeck
  onPass onBless onSuper
  disabled                             // true during card animation
/>
