02 · Profile detail sheet

Tap card · sheet rises · decide from inside

Sheet variant=full (92% detent). Drag-handle 36×4. Scrollable bio + photos + prompts + faith details. Sticky footer pinned with Pass + Bless action buttons (smaller — 56pt / 64pt — to match sheet scale).

Open trigger
Tap on top card (no drag detected within 120ms), OR long-press 240ms (haptic Medium fires at hold). Tap-anywhere on card except action buttons.
Sheet animation
Slide up from bottom · 320ms ease-emphatic · scrim fades 0 → 0.42
Dismiss
Drag handle down · OR tap scrim · OR back gesture · OR commit via footer button (auto-dismiss + commit).
Footer actions
Pass (left, 56pt) · Bless (right, 64pt). NO Super-Bless in detail (intentional friction — Super only via gesture or main deck button).
Footer commit flow
1. Haptic fires · 2. Sheet slides down 240ms · 3. Card commits in chosen direction (320ms exit, 200ms next-card rise) · 4. Total: ~560ms tap-to-next.
Photo carousel
Horizontal swipe within sheet content area. Page indicators (gold dots) at top of photo. Swipe down still dismisses sheet — gesture handler distinguishes.
Scroll lock
Sheet content scrollable. Drag-down ONLY dismisses when scroll position is at top + drag exceeds 60pt. Otherwise scrolls list.

03b · Verse interlude

Every five swipes, a breath

A verse card slides into the deck after every 5 consecutive profile commits. Same physical slot, different intent. Breaks the swipe-loop, anchors faith identity. Try it in the demo — the gold dots above the deck count up; on the 5th, an interlude is queued.

PropertySpec
TriggerEvery INTERLUDE_EVERY = 5 profile-card commits (pass / bless / super all count). Counter resets after each interlude. Counter shown as 5 dots above deck (gold = filled).
VisualSandstone-warm fill (no photo) · gold rule above + below verse · serif italic h3 verse text · uppercase eyebrow ("A breath") · uppercase reference (cobalt-700)
DraggingNO Pass/Bless/Super overlay tags. Card opacity fades 1.0 → 0.5 with drag distance only. Tells user: "this isn't a decision."
DismissalSwipe any direction (same thresholds). Tap also dismisses. NO commit recorded — just a breath. Streak counter is NOT incremented.
Long-pressnoop. No detail sheet for verse cards.
HapticsOn dismiss: light impact only (no Success notification — interlude is not an affirmative action).
Reduced motionVerse cross-fades in/out 200ms instead of slide.
Verse sourceCurated server-side list (faith-aligned, pastor-reviewed). v1 ships ~30 verses; rotate by deterministic hash of (userId, day) to avoid repeats.
Frequency tuningPer-user override possible (admin / experiment). Default 5. Min 3, max 10.

Why. Most dating apps reward continuous swiping with dopamine variable-ratio reinforcement. Cathedral Light explicitly refuses that loop. The interlude is a pacing brake, a reminder of why this app exists. Faith first, swipe second.

07 · RN API additions

SwipeDeck + ProfileDetailSheet

type DeckItem = ProfileCard | VerseInterlude;
type ProfileCard = { kind: 'profile', id, name, age, ... };
type VerseInterlude = { kind: 'verse', id, verse, reference };

<SwipeDeck
  items={DeckItem[]}                       // mixed profile + interlude
  onCommit={(item, action: 'pass' | 'bless' | 'super' | 'dismiss') => void}
  onPeek={(profileId) => void}             // only fires on profile cards
  onEmpty={() => void}
  interludeEvery?={5}                      // streak threshold; default 5
  reducedMotion?={boolean}
/>

<ActionDeck
  onPass onBless onSuper
  disabled                                 // true during animation OR on interlude top
  // sizing locked: pass 56pt · bless 80pt · super 56pt
  // gap 28pt · bless gold-rule below
/>

<ProfileDetailSheet
  card={Card | null}                       // null = closed
  onDismiss={() => void}
  onAction={(action: 'pass' | 'bless') => void}  // sheet auto-dismisses, parent fires deck commit
/>

// composition in screen:
function PeopleScreen() {
  const [peeking, setPeeking] = useState<Card | null>(null);
  const deckRef = useRef<SwipeDeckHandle>(null);

  return (
    <>
      <SwipeDeck
        ref={deckRef}
        cards={cards}
        onCommit={recordSwipe}
        onPeek={setPeeking}
        onEmpty={showEmptyState}
      />
      <ProfileDetailSheet
        card={peeking}
        onDismiss={() => setPeeking(null)}
        onAction={(action) => {
          setPeeking(null);
          deckRef.current?.commit(action);   // imperative — fires same animation
        }}
      />
    </>
  );
}

Deck restock orchestration

// SwipeDeck internal state
const stack = useSharedValue(cards.slice(0, 4));   // top + 2 behind + 1 prefetch

function handleCommit(action) {
  // 1. Top card exits (320ms)
  topCardX.value = withTiming(action === 'pass' ? -W*1.2 : W*1.2, EXIT);
  topCardRotate.value = withTiming(action === 'pass' ? -18 : 18, EXIT);

  // 2. After 80ms delay, behind cards promote (200ms)
  setTimeout(() => {
    stack1Scale.value = withTiming(1, RISE);
    stack1Y.value = withTiming(0, RISE);
    stack1Opacity.value = withTiming(1, RISE);
    stack2Scale.value = withTiming(0.94, RISE);
    // ... etc
  }, 80);

  // 3. After exit completes, mutate stack array, reset shared values
  setTimeout(() => {
    stack.value = [...stack.value.slice(1), nextCard()];
    resetSharedValues();
    onCommit(committed.id, action);
  }, EXIT.duration);
}
