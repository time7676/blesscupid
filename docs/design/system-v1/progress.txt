## Decisions locked

- Design system: `lib/design-system` canonical. Cobalt token kept defined but unused in user-facing surfaces (reserved for secondary states).
- Palette: Garden Hours — sandstone-warm + gold-soft + amber-ink (warning-700) as italic/accent, ink-black for buttons.
- Navigation: 3-stack split (Auth / Onboarding / AppShell) under Root. **Catechism stack removed.**
- Scope: polish + post-onboarding shell + empty/error/loading library + modal system + monetization patterns.
- App loop philosophy: Tinder/Bumble simplicity + heavy moderation (face liveness + 1-hour human review) + Christian-specific moments (verse-of-day, covenant ack, faith filtering, pastor-signed redirect on values mismatch).
- Monetization posture: "show the metric first, ask for the upgrade second." No banners, no countdown timers, no shame copy.
- Phase 0 scope: anchor set + iterate. v1.1 = 1 Welcome + 5 anchors + 4 modals = 10 frames.
