v1.1 — what changed since you reviewed v1.0

  1. Garden Hours wins. Sandstone-warm + gold-soft + amber-ink (warning-700) is the canonical chord. The Welcome hero now drifts over 14 seconds — pure CSS keyframes. RN port: react-native-reanimated shared-value loop.
  2. Cobalt is retired from user-facing surfaces. All italic emphasis, active states, selected chips, and selected radios use the amber ramp instead. Cobalt token stays defined for future secondary states.
  3. All primary buttons are ink-black. One button color across the app — no blue, no amber buttons. Amber is text/tint accent only.
  4. Catechism is out of the loop. Beat 1–8 onboarding ceremony is dropped per your direction. Verse-of-day card on Today carries the spiritual thread. Catechism content is preserved in i18n for a future "reading room" feature, not entry-flow. Plan §6 navigation simplifies; plan Phase 3 (Catechism remap) is cancelled and replaced with "Verse-of-Day + Reading Room (deferred)".
  5. Monetization landed gently. Today now has a "Profile views" card that shows an aggregate metric, then gates the identity reveal behind Bless+. No banner ads, no countdown timers, no shame copy. The pattern is: show the number first, ask for the upgrade second.
  6. You has a plan-tier row. "Account · Free" or "Bless+ · 12 days left" sits at the top of the settings list with an inline upgrade affordance. Single source of truth for tier status across the app.
  7. New §C section: Modals & overlays. Four canonical patterns — notification banner, one-time offer, gated-feature paywall, Q3 redirect — that every other modal in the app inherits from. Sheet primitive from plan §3 carries them all.
  8. App loop reaffirmed. Tinder/Bumble simplicity (open → see today's three → tap → talk) + heavy moderation (face liveness + 1-hour human review) + Christian-specific moments (verse-of-day, covenant ack, faith filtering, pastor-signed redirect on values mismatch).
