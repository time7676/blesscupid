# BlessCupid App Icon Concepts

## Options

1. **Dawn Path** — warm arch + two paths meeting. Best balance for dating app: mature, hopeful, not boring.
2. **Open Window** — chapel-light abstraction without literal church symbol. Most ownable.
3. **Soft BC** — keeps monogram equity, but softer lowercase and less severe.
4. **Gold Leaf** — more living/garden feel. Better for wellness/community, less direct for dating.

Use **01 Dawn Path** for main app icon. It keeps sacred restraint but adds movement and warmth. Use **02 Open Window** as fallback if you want less “dating path” metaphor.
